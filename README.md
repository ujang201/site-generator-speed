A faster drop-in for makefun-site 1.0.0: `solve.js` answers every case with exactly the output tree makefun-site returns, byte for byte, in less CPU time. Single-pass Markdown rendering, bulk HTML escaping, cached slugs, and templates rendered into one joined string.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
